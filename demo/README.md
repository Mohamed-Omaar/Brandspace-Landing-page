# BrandSpace Demo

This directory exposes the reviewed **BrandSpace Minimal UI Concept** under `/demo`.

Source demo:
https://brandspace-minimal-ui-concept.imokfax.chatgpt.site/

`index.html` intentionally embeds the reviewed published demo full-screen so the visual result matches the approved concept exactly.

Note: the ChatGPT Site projection does not currently expose an exportable source bundle through the connected file interface. This means the `/demo` page depends on the published source URL until a standalone source bundle is available.
