# BrandSpace Demo

Standalone static product demo served from `/demo`.

Files:
- `index.html` — application shell and demo screens
- `styles.css` — responsive BrandSpace UI
- `app.js` — navigation and demo interactions

This demo is hosted entirely from the Brandspace-Landing-page repository and does not depend on `auth.openai.com`, ChatGPT Site embedding, an iframe, or an external redirect.
